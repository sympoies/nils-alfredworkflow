# Binary release manifest for the nils-alfred-cli standalone bundle.
#
# Format:
#   binary-name|crate-dir|release note
#
# Include CLIs that can be used directly from a terminal without Alfred. Tools
# may still require normal product setup, such as OAuth login, but should not
# require Alfred-only runtime state or an external scraper process.
bangumi-cli|crates/bangumi-cli|Public Bangumi subject search; legacy JSON-first output.
bilibili-cli|crates/bilibili-cli|Public Bilibili suggestion search; legacy JSON-first output.
epoch-cli|crates/epoch-cli|Local epoch and datetime conversion.
google-cli|crates/google-cli|Google auth, Gmail, Drive, and Calendar CLI; requires `auth credentials set` plus `auth add` before use.
market-cli|crates/market-cli|Public FX and crypto market lookup; partial human-output migration.
quote-cli|crates/quote-cli|Quote feed refresh and filtering; legacy JSON-first output.
randomer-cli|crates/randomer-cli|Local random value generation.
steam-cli|crates/steam-cli|Public Steam Store search and specials with service JSON mode.
timezone-cli|crates/timezone-cli|Local multi-timezone conversion.
weather-cli|crates/weather-cli|Weather forecast CLI with human, JSON, and Alfred output modes.
wiki-cli|crates/wiki-cli|Wikipedia search with structured output.
workflow-cli|crates/workflow-cli|Shared project workflow helper with human, JSON, and Alfred output modes.
workflow-readme-cli|crates/workflow-readme-cli|Workflow README conversion and plist injection tool.
