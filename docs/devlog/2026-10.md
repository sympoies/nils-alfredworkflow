# Development log - 2026-10

## 2026-10-18 - Preserve Calendar action identities in failure envelopes

### Result

- Calendar failures now identify supported actions, including create and update
  invalid-input errors; unresolved actions retain generic group IDs.

### Why / context

- Consumers correlate diagnostics to the invoked action. Resolve only supported
  action tokens so an unknown token cannot become a claimed command identity.

### Evidence

- Before production edits, both create/update invalid-flag regressions failed
  with generic IDs (exit 101). After the fix, cargo test -p nils-google-cli
  --test integration calendar_read:: passed all 14 tests, covering every
  supported action, group aliases, fallback IDs, schema and error codes.
